# 🧠 Brain Tumor Classification using VGG16 A deep learning project for automatic **Brain Tumor Classification** from MRI images using **Transfer Learning** with the **VGG16** Convolutional Neural Network (CNN). The model classifies brain MRI scans into multiple tumor categories after applying image preprocessing and augmentation techniques. --- ## 📖 Overview Brain tumor diagnosis from MRI images is a challenging task that requires expertise and time. This project utilizes a pre-trained **VGG16** model to automatically classify MRI images into different brain tumor classes, demonstrating the effectiveness of transfer learning in medical image analysis. --- ## 🚀 Features - Transfer Learning using VGG16 - MRI image classification - Image augmentation (brightness & contrast) - Image normalization - Automatic label encoding - Batch data generator - Multi-class classification - Model saving after training --- ## 🛠️ Tech Stack - Python - TensorFlow - Keras - NumPy - Pillow (PIL) - Matplotlib - Scikit-learn ---
